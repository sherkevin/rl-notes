# 经验回放 (Experience Replay)

> Off-Policy学习的核心机制

## 定义
经验回放是一种通过存储和重用历史交互数据来提高样本效率的技术。

## 工作原理

### 存储阶段
```python
经验回放池 D = []  # 存储四元组 (s, a, r, s')
for each 交互:
    执行动作 a，获得 r, s'
    D.append((s, a, r, s'))  # 存储经验
```

### 学习阶段
```python
从 D 中随机采样一批经验
使用这些经验更新网络
```

## 优势
1. **数据复用** - 一次交互可以多次学习
2. **打破相关性** - 随机采样使数据更独立
3. **实现Off-Policy** - 学习策略≠数据生成策略
