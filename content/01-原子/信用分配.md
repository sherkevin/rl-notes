# 信用分配（Credit Assignment）

> 团队协作时，如何把全局奖励分配给每个 agent？

---

## 一句话定义

**信用分配 = 团队赢了/输了，谁的贡献大？**

---

## 问题形式化

**全局奖励**：$R(s, a_1, \ldots, a_n)$

**问题**：每个 agent $i$ 应该得到多少奖励 $r_i$？

$$r_i = \text{Credit}(i, R, s, a_1, \ldots, a_n)$$

---

## 三种方法

### 1. Difference Reward（差分奖励）

$$D_i(s, a_i) = R(s, a_i, a_{-i}) - R(s, a_i^0, a_{-i})$$

其中 $a_i^0$ 是"什么都不做"的动作。

**直觉**：agent $i$ 的贡献 = 有它 vs 没它。

**优点**：简单直观。

**缺点**：需要定义"什么都不做"。

### 2. Shapley Value（沙普利值）

$$\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(n-|S|-1)!}{n!} [v(S \cup \{i\}) - v(S)]$$

**直觉**：agent $i$ 对所有可能联盟的边际贡献的加权平均。

**性质**（唯一满足以下四条）：
1. **效率**：$\sum_i \phi_i = v(N)$
2. **对称性**：贡献相同 → 分配相同
3. **虚拟玩家**：贡献为 0 → 分配为 0
4. **可加性**：$\phi_i(v + w) = \phi_i(v) + \phi_i(w)$

**缺点**：计算复杂（$O(2^n)$）。

### 3. Counterfactual Multi-Agent（COMA）

$$A_i(s, a_i) = Q(s, a_i, a_{-i}) - \sum_{a_i'} \pi_i(a_i' | o_i) Q(s, a_i', a_{-i})$$

**直觉**：agent $i$ 的实际动作 vs 策略的期望动作。

**优点**：可以直接用于 policy gradient。

**缺点**：需要集中式 Q 函数。

---

## 对比

| 方法 | 计算复杂度 | 公平性 | 适用场景 |
|------|-----------|--------|----------|
| Difference Reward | $O(1)$ | 中 | 简单合作任务 |
| Shapley Value | $O(2^n)$ | 高（理论最优） | 小团队（$n < 10$） |
| COMA | $O(n)$ | 中 | Policy gradient |

---

## 应用场景

- **足球**：进球了，谁传的好？谁射的好？
- **自动驾驶车队**：整体通行效率高，哪辆车贡献大？
- **星际争霸**：赢了，哪个单位的操作关键？

---

## 演化位置

```
Team reward (1990s)：所有 agent 分相同奖励
    ↓
Difference Reward (2002)：有 vs 没
    ↓
Shapley Value (2007)：公平分配
    ↓
COMA (2018)：反事实推理
```
