# 目标网络 (Target Network)

> 稳定[[02-模块/Value-Based/DQN|DQN]]训练的关键技巧

## 定义
目标网络是主网络的一个副本，参数定期从主网络同步，用于计算稳定的训练目标。

## 问题：追逐移动靶

在原始[[02-模块/Value-Based/DQN|DQN]]中，使用同一个网络计算目标和预测：
```
y = r + γ·max Q(s', a'; θ)  # 目标
Q(s, a; θ)                  # 预测
```

每次更新θ后，目标y也会变化，导致训练不稳定。

## 解决方案

### 双网络结构
```
主网络 Q(θ)       - 实时更新
目标网络 Q(θ⁻)    - 定期同步
```

### 稳定目标
```
y = r + γ·max Q(s', a'; θ⁻)  # 使用目标网络
```

### 更新流程
```
1. 训练主网络 θ
2. 每C步同步: θ⁻ ← θ
```
