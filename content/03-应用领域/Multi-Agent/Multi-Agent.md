# Multi-Agent RL

Reinforcement learning involving multiple interacting agents.

## Overview
Agents must learn while considering actions of other agents, leading to complex dynamics.

## Challenges
- Non-stationary environments
- Coordination and communication
- Credit assignment

## Related Algorithms
- [[MADDPG]]
- [[QMIX]]
- [[MAPPO]]

- vs [[Single-Agent]]: Multiple learners with interactions
