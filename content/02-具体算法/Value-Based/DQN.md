## Q-Learning
[[Bellman方程和TD误差]]
Q-Learning是一种off-policy TD算法，伪代码如下：

首先，我们会初始化一张Q表，用于记录状态-动作对的值，在每一个episode的每一步都会根据公式更新Q表

Q-Learning很好的解决了迷宫问题，但是大部分问题都是有巨大的状态空间或动作空间，想建立一个Q表，内存是不允许的，数据量和时间开销也是一个问题。  

## DQN

Deep Q Network将Q-Learning与神经网络结合，**将Q-Learning的Q表换成了Q-Network。**

值函数近似（Function Approximation）方法就是为了解决状态空间过大，即“维度灾难”的问题。**通过用函数而不是Q表来表示 ，这个函数可以是线性的也可以是非线性的。**
$$
 \widehat { v } ( s , w ) \approx v _ { \pi } ( s ) o r  \widehat { q } ( s , a , w ) \approx q _ { \pi } ( s , a )
$$


训练样本通过$\epsilon-greedy$策略生成。我们可以使用计算得到的Q值作为监督学习的标签来设计loss函数，采用如下形式，即近似值和真实值的均方差：  
$$
 J \left( w \right) = E _ { \pi } \left[ ( q _ { \pi } \left( s , a \right) - \widehat { q } \left( s , a , w \right) ) ^ { 2 } \right]
 $$
![image.png](https://gitee.com/sherkevin/pictures/raw/master/20251009142428.png)
更新方法：增量法、批处理法。一般使用批处理法，攒一堆样本再从中采样一部分用来更新Q-Network，这称为 “经验回放”。 好处：假设样本是独立同分布的，**强化学习采集到的数据之间存在关联性，利用这些数据进行顺序训练，神经网络不稳定，经验回放可以打破数据间的关联。**

### 第一部分：“经验回放” (Experience Replay)

这部分描述的是标准DQN算法的学习更新步骤。

1. 随机采样多个transition, 计算TD error: $δ = Q(s_i, a_i; w) - [r_t + Q(s_{i+1}, a_{i+1}; w)]$
- **这是什么？** 这就是在计算我们之前讨论过的**TD误差 (δ)**。
- $Q(s_i, a_i; w)$: 这是我们当前的Q网络（参数为`w`）对于采样到的状态`s_i`和动作`a_i`所做出的 **“价值预测”**。
- $[r_t + Q(s_{i+1}, a_{i+1}; w)]$: 这是我们根据“走了一步”的经验，计算出的 **“更靠谱的目标值” (Target)**。
- **`δ`**: 就是“预测值”和“目标值”之间的差距。

> **一个小提示**：您可能会注意到，这个目标值的写法 $Q(s_{i+1}, a_{i+1}; w)$ 实际上是 **SARSA (On-Policy)** 的形式，因为它用了下一步实际的动作$a_{i+1}$。而DQN (Off-Policy) 应该用 $max_{a'} Q(s_{i+1}, a'; w)$

2. 求导: $g_i = ∂(δ_i²/2) / ∂w = δ_i ⋅ ∂Q(s_i, a_i; w) / ∂w$
- **这是什么？** 这是在计算**损失函数 (Loss Function) 的梯度 (Gradient)**。梯度告诉我们应该朝哪个方向调整网络参数`w`，才能让TD误差变小。
- **`L = δ_i²/2`**: 这是损失函数，即**均方误差 (MSE)**。我们希望这个误差的平方尽可能小。
- **`∂(...) / ∂w`**: 这是微积分中的求导符号，表示计算“损失”相对于“网络参数`w`”的变化率。
- **`g_i = ...`**: 这是使用链式法则求导后的最终结果。

2. 采样多次, 使用梯度均值进行SGD
- **这是什么？** 这描述了**批量更新 (Batch Update)** 的过程。
- **含义**：我们不会只用一条经验就更新一次网络。而是从经验回放池里**随机采样一批**（比如64条）经验，为每一条经验都计算出梯度`g_i`。然后，我们把这64个梯度**求一个平均值**，用这个平均梯度来对网络参数`w`进行一次更新（使用SGD或Adam等优化器）。这样做比单条更新更稳定、更高效。

### 第二部分：“优先经验回放” (Prioritized Experience Replay - PER)

这是对标准经验回放的一个重要改进。
**核心思想**：不是所有的“经验”都同等重要。那些让我们“大吃一惊”（即TD误差很大）的经验，包含的学习信息更多，我们应该更频繁地从这些经验中学习。

**1. `sampling probability: p_t ∝ |δ_t| + ε`**

- **这是什么？** 这是定义**采样概率**的第一种方法。
- **`p_t ∝ ...`**: `∝` 符号表示“正比于”。意思是，某条经验`t`被抽中去学习的概率`p_t`，与它的TD误差的绝对值`|δ_t|`成正比。
- **`|δ_t|`**: TD误差的绝对值。误差越大，说明网络预测得越不准，这条经验越“令人惊讶”，也就越有学习价值。
- **`+ ε`**: `ε`是一个很小的正常数，目的是为了保证即使某条经验的TD误差为0，它仍然有微小的概率被抽中，避免完全不被学习。

**2. `sampling probability: p_t ∝ 1 / rank(t)`**
- **这是什么？** 这是定义采样概率的第二种方法，基于**排名 (Rank)**。
- **a. `transitions按照|δ_t|排序`**: 首先，把经验池里所有的经验，都按照它们的`|δ_t|`从大到小排个序。
- **b. `rank(t)`**: 得到经验`t`在这个排序中的名次（第1名，第2名，...）。
- **`p_t ∝ 1 / rank(t)`**: 采样概率和它的**名次的倒数**成正比。这意味着，第1名的经验（误差最大）被抽中的概率最高，第2名次之，以此类推。这种方法比直接用`|δ_t|`更稳定，可以避免少数误差极大的样本“霸占”所有的采样机会。

**3. `另外, 应该对学习率进行scale: (n p_i)^-β`**
- **这是什么？** 这是**重要性采样权重 (Importance Sampling Weight)**，用来修正偏差。
- **为什么需要？** 因为我们“作弊”了。我们没有进行均匀随机采样，而是有偏好地、更多地去学习那些“重要”的经验。这会导致模型对这些重要经验产生“过拟合”，从而引入了偏差。
- **如何修正？** 为了消除这种偏差，我们需要在计算梯度更新时，给那些被我们“偏爱”的、采样概率`p_i`更高的样本，**乘以一个更小的权重**，来降低它们在更新中的影响力。
- **`(n p_i)^-β`**: 这就是那个权重。`n`是经验池大小，`p_i`是采样概率。这个公式确保了采样概率越高的样本，其权重越低。`β`是一个超参数，控制修正的强度。
    

**总结**：这些公式详细描述了DQN的“大脑”是如何工作的：通过**TD误差**这个核心信号来感知“对与错”，通过**梯度**来指导“如何改正”，并通过**优先经验回放**这个“聪明的复习策略”来聚焦于“最需要学习的知识点”。  

## 高估问题
计算$q_{t+1}$时，会进行最大化选择，所以会造成高估t+1步的真实价值；  
的高估导致TD target的高估；  
而TD learning会引导价值网络向高估的价值方向学习，所以导致价值网络高估。  

![](https://tc-cdn.flowus.cn/oss/0a9e6803-3155-41c6-b47f-425c22e2b5f6/image.png?time=1759988700&token=e3b2eb7e37136e602ccf14744c48c59d4323d51e24ed13cf06e32977f6961972&role=sharePaid)

自举：因为价值网络已经高估，现在用高估的价值网络预测新的TD target，会进一步高估（螺旋起飞）。  

![](https://tc-cdn.flowus.cn/oss/bd4c7f2b-cecc-433c-837f-790175bba728/image.png?time=1759988700&token=404ce6087b83231a53f19f9450ff673afe29575adf966969b8f9d00901ee56b1&role=sharePaid)

高估本身不是问题，只要高估是均匀的，问题在于不均匀高估（这才是实际的）。

### 1. Target Network：解决“追逐移动靶”的不稳定问题
首先，我们来看Target Network。它主要解决的，其实是由于目标不稳定而间接导致的高估和训练发散问题。
#### a. 问题是什么？
在最原始的Q-Learning更新中，TD目标是这样计算的：

$$
y = r + γ * max_{a'} Q_θ(s', a')
$$

请注意，我们用来计算“目标值 `y`”的網絡 `Q_θ`，和我们正在训练的、需要去“靠近”这个目标值的網絡 `Q_θ`，是**同一个网络**。

**这就好比一个学生在做一套练习题，但他用来给自己评分的“标准答案”，是他自己刚刚随手写的。**
每当他学了一点新知识（更新了参数`θ`），他的“标准答案”（TD目标）也立刻跟着变了。这个过程非常不稳定，就像是在**用一把晃动不定的尺子去测量一个物体**，或者说，**“狗在追自己的尾巴”**。这种不稳定性很容易导致Q值的估计出现震荡，并且会累积误差，从而造成高估。

#### b. Target Network如何解决？
Target Network 的思想非常简单：**“把尺子先固定住！”**
1. **创建副本**：我们创建两个Q网络，结构完全相同。
    - **主网络 (Main Network) `Q_θ`**：这是我们一直在积极训练、实时更新的网络。它就是那个努力学习的“学生”。
    - **目标网络 (Target Network) `Q_{θ'}`**：这是主网络的一个**副本**。它的参数`θ'`在一开始会从主网络`θ`复制过来，但之后会被 **“冻结”**，在一段时间内保持不变。它就是那本 **“暂时固定的标准答案”**。

2. **分工合作**：
    - 在计算TD目标时，我们只使用稳定不变的目标网络 Q_{θ'}。
        $$
        y = r + γ * max_{a'} Q_{θ'}(s', a')
        $$
    - 在训练时，我们只更新**主网络 `Q_θ`** 的参数，让它的预测 `Q_θ(s, a)` 向这个**稳定的目标`y`** 靠拢。
        
3. **定期同步**：每隔一大段时间（比如每10000步），我们才把主网络`Q_θ`的最新参数，**复制**给目标网络`Q_{θ'}`，给“学生”换一本新的、更准确的“标准答案”。
    
**效果**：通过这种方式，学习的目标在短期内是固定的，主网络有了一个稳定的追赶方向，使得整个训练过程变得更加稳定，从而缓解了因震荡累积导致的高估问题。


### 2. Double DQN (DDQN)：解决 `max` 操作带来的“盲目乐观”问题
Target Network 解决了不稳定的问题，但还有一个更根本的高估来源没有解决，那就是 `max` 操作本身。
#### a. 问题是什么？(Maximization Bias)

`max` 操作天生就是“乐观”的。我们的Q网络因为是近似估计，所以它的输出值总会有一些随机的误差（噪声）。

比喻：“过于自信的招聘经理”

假设一个招聘经理（Q网络）要评估3个候选人（3个动作），他们的真实能力（真实的Q值）都是5分。但经理的评估有误差，他给出的分数可能是 {4.8, 5.2, 4.9}。
- **标准的DQN会怎么做？** 它会执行 `max` 操作，选出那个分数最高的候选人，然后认为这个岗位的价值就是 **5.2** 分。
    
- **问题在哪？** `max` 操作总是倾向于选择那些 **被正向误差“眷顾”** 的动作。即使所有动作的真实价值都一样，只要存在估计误差，`max` 操作就会系统性地挑选出那些被高估的值，导致最终学习到的价值期望**总是高于**真实的价值期望。这种“盲目乐观”就是**最大化偏差**。

#### b. Double DQN如何解决？
Double DQN 的思想绝妙，它引入了**分权制衡**，将“**挑选动作**”和“**评估动作**”这两个职能分开。
1. **角色分工**：它正好利用了我们已经有的主网络`Q_θ`和目标网络`Q_{θ'}`。
    - **主网络 `Q_θ`**：负责当“**动作挑选官**”。它的任务是，在下一个状态`s'`，找出它认为最好的动作是哪一个。
    - **目标网络 `Q_{θ'}`**：负责当“**价值评估官**”。它的任务是，对“挑选官”选出来的那个动作，给出一个独立的、更稳健的价值评估。
        
2. 新的更新公式：
    $$
    y = r + γ * Q_{θ'}(s', argmax_{a'} Q_θ(s', a'))
    $$
    
    我们来拆解这个公式的核心部分 `Q_{θ'}(s', ...)`：
    - 第一步 (挑选)：$argmax_{a'} Q_θ(s', a')$
        主网络Q_θ先在s'状态下，比较所有a'，找出那个它认为Q值最高的动作。比如，它挑出了动作 a*。
        
    - 第二步 (评估)：$Q_{θ'}(s', a*)$
        然后，我们不用主网络Q_θ自己给出的那个可能被高估的分数，而是把挑出来的动作 a* 交给目标网络 Q_{θ'} 去进行二次评估，得到一个更冷静的价值。

效果：一个动作的价值被高估，通常是随机误差导致的。现在，一个动作必须同时被主网络Q_θ认为“最好”（被选中），并且被独立的目标网络Q_{θ'}也给出一个很高的评分，它的价值才会被认为是真的高。一个动作恰好在两个独立的网络中都被随机误差“眷顾”的概率，要比在单个网络中小得多。这就大大缓解了最大化偏差，使得价值评估更加准确。
