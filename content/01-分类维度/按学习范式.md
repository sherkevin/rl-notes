# 按学习范式分类 (Learning Paradigm)

强化学习算法根据如何表示价值函数或策略，可以分为表格型方法和函数逼近方法。

---

## Tabular Methods (表格型方法)

### 定义
使用表格（Q表或V表）显式存储每个状态或状态-动作对的价值。适用于状态空间较小的场景。

### 核心特征
- **显式存储**: 用数组/表格存储每个状态的值
- **精确存储**: 对访问过的状态有精确的价值估计
- **状态限制**: 只能处理有限、离散的状态空间

### 技术细节

#### Q表 (Q-Table)
```
Q-Table 示例：状态空间=4，动作空间=2

        动作1    动作2
状态1   0.5      0.3
状态2   1.2      0.8
状态3   0.1      2.5
状态4   3.0      1.5

访问：Q[state, action] 直接查表
```

#### 更新公式
```python
# Q-Learning 更新
Q[s, a] = Q[s, a] + α * (r + γ * max Q[s', :] - Q[s, a])
                     ↑
                     TD误差
```

### 典型算法
- [[Q-Learning]] - Off-Policy
- [[SARSA]] - On-Policy

### 优点
- ✅ 理论完备，收敛性有保证
- ✅ 实现简单直观
- ✅ 对小状态空间问题效果最好
- ✅ 不需要调整神经网络参数

### 缺点
- ❌ **维度灾难**：状态空间过大时无法存储
- ❌ 泛化能力差（无法推广到未访问状态）
- ❌ 不适合复杂环境（如图像、高维传感器）

### 适用场景
- ✅ 迷宫问题（Grid World）
- ✅ 简单游戏（如Tic-Tac-Toe）
- ✅ 状态离散且数量少的问题（<10⁶状态）

---

## Function Approximation (函数逼近)

### 定义
使用函数（通常是神经网络）来近似价值函数或策略，将状态映射到价值或动作。

### 核心特征
- **参数化表示**: V(s; w) ≈ V_π(s) 或 Q(s,a; w) ≈ Q_π(s,a)
- **泛化能力**: 可以处理未见过的状态
- **高维处理**: 可以处理图像、文本等高维输入

### 技术细节

#### 网络结构
```python
# Value-Based: DQN
Q_values = DQN_Network(state)  # 输出每个动作的Q值
# 状态 → 神经网络 → Q(s, a₁), Q(s, a₂), ..., Q(s, aₙ)

# Policy-Based: PPO
action_probs = Policy_Network(state)  # 输出动作概率分布
# 状态 → 神经网络 → π(a₁|s), π(a₂|s), ..., π(aₙ|s)

# Actor-Critic: SAC
action = Actor_Network(state)         # Actor输出动作
Q_value = Critic_Network(state, action)  # Critic评估Q值
```

#### 更新方法
使用梯度下降优化网络参数：
```python
# 损失函数
L(w) = E[(y - Q(s,a; w))²]  # MSE损失
# y是目标值，Q(s,a; w)是当前预测

# 梯度更新
w ← w - α · ∇L(w)
```

### 典型算法

#### Value-Based
- [[DQN]] - Deep Q-Network
- [[DDQN]] - Double DQN
- [[CQL]] - Conservative Q-Learning

#### Policy-Based
- [[REINFORCE]] - 基础策略梯度
- [[PPO]] - Proximal Policy Optimization
- [[TRPO]] - Trust Region Policy Optimization

#### Actor-Critic
- [[A3C]] / [[A2C]] - Asynchronous/Synchronous Actor-Critic
- [[DDPG]] - Deep Deterministic Policy Gradient
- [[TD3]] - Twin Delayed DDPG
- [[SAC]] - Soft Actor-Critic

### 优点
- ✅ 解决维度灾难（状态空间再大也不怕）
- ✅ 有泛化能力（相似状态有相似价值）
- ✅ 可以处理高维输入（图像、传感器数据）
- ✅ 适合复杂现实任务

### 缺点
- ❌ 训练不稳定（需要各种技巧）
- ❌ 超参数敏感（学习率、网络结构等）
- ❌ 收敛性没有理论保证
- ❌ 计算资源需求大

### 适用场景
- ✅ Atari游戏（图像输入）
- ✅ 机器人控制（高维传感器）
- ✅ 自动驾驶（复杂环境）
- ✅ 任何状态空间巨大的问题

---

## 对比总结

| 维度 | 表格型 (Tabular) | 函数逼近 (Function Approx) |
|:---|:---|:---|
| **表示方式** | Q表/V表 | 神经网络/线性函数 |
| **存储方式** | 显式存储每个状态 | 参数化函数 |
| **状态空间** | 有限、离散 | 任意（包括连续） |
| **泛化能力** | ❌ 无泛化 | ✅ 有泛化 |
| **维度灾难** | ❌ 严重 | ✅ 不受影响 |
| **实现难度** | 简单 | 复杂 |
| **训练稳定性** | 稳定 | 不稳定 |
| **理论保证** | 收敛性有保证 | 无理论保证 |
| **典型算法** | Q-Learning, SARSA | DQN, PPO, SAC |
| **适用规模** | <10⁶状态 | 任意规模 |

## 从表格到函数的演进

```
问题升级
    ↓
状态空间增大（从4个状态到100万+）
    ↓
表格方法失效（内存爆炸）
    ↓
引入函数逼近
    ↓
Q(s,a) → Q(s,a; w)  # 用神经网络近似
    ↓
实现：DQN = Q-Learning + 神经网络
    ↓
问题：训练不稳定
    ↓
解决方案：
  - 经验回放（打破数据相关性）
  - 目标网络（稳定训练目标）
  - 梯度裁剪（防止梯度爆炸）
  - 各种正则化技术
```

---

## 技术挑战与解决方案

### 函数逼近的挑战

#### 1. 数据相关性
**问题**：顺序采集的数据相关性太强
**解决**：[[经验回放]] (Experience Replay)

#### 2. 目标不稳定
**问题**：用同一个网络计算目标和预测
**解决**：[[目标网络]] (Target Network)

#### 3. 价值高估
**问题**：max操作导致系统性高估
**解决**：[[DDQN]] (Double DQN)

#### 4. 策略崩溃
**问题**：策略更新步长过大导致性能骤降
**解决**：[[PPO]] 的裁剪机制、[[TRPO]] 的信赖域

---

## 选择建议

### 使用表格型方法，如果：
- ✅ 状态空间小（<10⁶）
- ✅ 需要理论保证
- ✅ 快速原型验证

### 使用函数逼近方法，如果：
- ✅ 状态空间大或连续
- ✅ 需要处理高维输入（图像等）
- ✅ 需要泛化能力
- ✅ 解决现实世界复杂问题

## 代码对比

### 表格型 Q-Learning
```python
# 初始化Q表
Q_table = np.zeros((n_states, n_actions))

# 更新
Q_table[state, action] += alpha * (
    reward + gamma * np.max(Q_table[next_state]) - Q_table[state, action]
)

# 决策
action = np.argmax(Q_table[state])
```

### 函数逼近 DQN
```python
# 初始化神经网络
Q_network = nn.Sequential(
    nn.Linear(state_dim, 128),
    nn.ReLU(),
    nn.Linear(128, 128),
    nn.ReLU(),
    nn.Linear(128, n_actions)
)

# 更新（通过优化器）
loss = mse(Q_network(state), target_Q)
optimizer.zero_grad()
loss.backward()
optimizer.step()

# 决策
action = torch.argmax(Q_network(state)).item()
```
