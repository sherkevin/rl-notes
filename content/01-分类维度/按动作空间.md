# 按动作空间分类 (Action Space)

强化学习算法根据动作空间的性质可以分为处理离散动作和连续动作两大类。

---

## Discrete Actions (离散动作)

### 定义
动作空间是有限的、可数的离散集合。智能体在每个状态下只能从有限的动作集合中选择一个动作。

### 特征
- **动作集合**: A = {a₁, a₂, ..., aₙ}，n是有限整数
- **输出形式**: 输出每个动作的概率或Q值
- **选择方式**: Argmax选择（确定性）或采样（随机）

### 典型场景
- 🎮 Atari游戏：上下左右
- 🎯 棋类游戏：落子位置
- 📦 仓储调度：选择哪个货架
- 🚦 交通控制：红绿灯状态

### 适用算法

#### Value-Based方法
- [[Q-Learning]] - 输出每个动作的Q值
- [[DQN]] - 用神经网络估计Q(s,a)
- [[SARSA]] - On-Policy版本

#### Policy-Based方法
- [[REINFORCE]] - 策略梯度
- [[PPO]] - 可以处理离散动作

### 技术细节
```python
# 离散动作网络输出
# 动作空间: A = {0, 1, 2, 3, 4}  (5个动作)

# Value-Based: 输出Q值
Q_values = neural_network(state)  # shape: [batch_size, 5]
action = argmax(Q_values)          # 选择最大Q值的动作

# Policy-Based: 输出概率分布
action_probs = softmax(neural_network(state))  # shape: [batch_size, 5]
action = sample(action_probs)                  # 按概率采样
```

### 优势
- ✅ 算法相对简单成熟
- ✅ Value-Based方法效果好
- ✅ 探索策略简单（如ε-greedy）

### 劣势
- ❌ 无法处理连续控制问题
- ❌ 动作数量不能太大（维度灾难）

---

## Continuous Actions (连续动作)

### 定义
动作空间是连续的实数空间。智能体在每个状态下需要输出一个或多个连续的数值。

### 特征
- **动作空间**: A ⊆ ℝⁿ（n维实数空间）
- **输出形式**: 输出动作的分布参数（均值μ、方差σ）
- **选择方式**: 从分布中采样

### 典型场景
- 🤖 机器人控制：关节角度、力矩
- 🚗 自动驾驶：方向盘角度、加速度
- 🎮 物理模拟：力、速度、位置
- ⚡ 能源管理：功率控制

### 适用算法

#### Policy-Based方法（主要方法）
- [[REINFORCE]] - 基础策略梯度
- [[PPO]] - 最常用，效果好
- [[TRPO]] - 理论保证的改进
- [[DDPG]] - Actor-Critic + DQN思想
- [[TD3]] - 改进DDPG
- [[SAC]] - 目前最先进的算法之一

#### 注意
- Value-Based方法（Q-Learning、DQN）**无法直接处理连续动作**
  - 因为无法对所有连续动作做max操作
  - 需要使用Actor-Critic或梯度方法

### 技术细节
```python
# 连续动作网络输出
# 动作空间: A = ℝ² (例如：控制力和方向)

# Policy-Based: 输出高斯分布参数
mu, log_std = neural_network(state)  # shape: [batch_size, 2]
std = exp(log_std)

# 从高斯分布采样动作
action = sample_normal(mu, std)       # 重参数化技巧
action = clamp(action, min_val, max_val)  # 限制动作范围

# Actor-Critic: Actor输出动作，Critic评估Q值
action = Actor(state)                 # Actor: 状态 → 动作
Q_value = Critic(state, action)       # Critic: 状态+动作 → Q值
```

### 探索策略
连续动作空间的探索方法：
1. **高斯噪声** - 添加高斯噪声到动作上
2. **OU过程** - Ornstein-Uhlenbeck过程（时序相关噪声）
3. **参数化噪声** - 在网络参数上添加噪声（如SAC）

### 优势
- ✅ 能处理现实世界的大多数控制问题
- ✅ 动作精细，适合精确控制

### 劣势
- ❌ 算法复杂度高
- ❌ 训练不稳定
- ❌ 样本效率低

---

## 对比总结

| 维度 | 离散动作 (Discrete) | 连续动作 (Continuous) |
|:---|:---|:---|
| **动作空间** | A = {a₁, ..., aₙ} | A ⊆ ℝⁿ |
| **动作数量** | 有限、可数 | 无限、不可数 |
| **输出形式** | Q值表或概率分布 | 分布参数 (μ, σ) |
| **动作选择** | Argmax或采样 | 从分布采样 |
| **主要算法** | Q-Learning, DQN | PPO, SAC, DDPG |
| **探索方式** | ε-greedy | 高斯噪声/OU过程 |
| **应用场景** | 游戏、棋类、调度 | 机器人、自动驾驶 |
| **算法难度** | 相对简单 | 复杂 |
| **训练稳定性** | 较好 | 较差 |

## 算法选择指南

### 判断标准
```
我的动作空间是离散的还是连续的？

→ 离散（有限选择）
   ├─ 简单场景 → Q-Learning
   ├─ 复杂场景 → DQN系列
   └─ 需要策略概率 → PPO (也可以)

→ 连续（控制问题）
   ├─ 最推荐 → PPO (稳定、易用)
   ├─ 追求性能 → SAC (样本效率高)
   └─ 传统方案 → DDPG/TD3
```

### 算法兼容性

| 算法 | 离散动作 | 连续动作 |
|:---|:---:|:---:|
| Q-Learning | ✅ | ❌ |
| DQN | ✅ | ❌ |
| SARSA | ✅ | ❌ |
| REINFORCE | ✅ | ✅ |
| PPO | ✅ | ✅ |
| TRPO | ✅ | ✅ |
| A3C/A2C | ✅ | ✅ |
| DDPG | ❌ | ✅ |
| TD3 | ❌ | ✅ |
| SAC | ❌ | ✅ |
| CQL | ✅ | ❌ (离散) / ✅ (连续版本) |

## 特殊情况

### 混合动作空间
有些问题既有离散动作又有连续动作：
- **例子**：机器人控制
  - 离散：选择使用哪个工具
  - 连续：控制工具的参数

**解决方案**：
1. 分层策略（Hierarchical Policy）
2. 多头网络（Multi-head Network）
3. 离散化连续动作（不推荐，损失精度）

### 动作离散化
将连续动作离散化，使其能用DQN等方法：
```python
# 连续动作: 控制力 ∈ [-10N, 10N]
# 离散化: {-10, -5, 0, 5, 10} 五档
```
- ❌ 精度损失
- ❌ 动作空间爆炸（如果分太细）
- ✅ 可以使用成熟的DQN算法
