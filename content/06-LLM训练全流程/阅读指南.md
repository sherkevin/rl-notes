## 主题 1：彻底搞懂 RLHF

> 目标：理解从 InstructGPT 到 ChatGPT 的完整对齐流程。

### 前置知识链（按顺序读）

```
1. [[01-原子/策略梯度]]          ← 策略优化的基础：∇J = E[∇logπ · G]
2. [[01-原子/KL散度]]            ← 理解"不要偏离太远"的数学含义
3. [[01-原子/Bradley-Terry模型]]  ← 偏好建模：P(yw > yl) = σ(rw - rl)
4. [[01-原子/重要性采样]]         ← 用旧数据估计新策略
5. [[01-原子/优势函数]]           ← A = Q - V，降低方差
6. [[01-原子/GAE]]               ← 广义优势估计，PPO 的标配
7. [[01-原子/Clip机制]]           ← 限制更新幅度，PPO 的核心
8. [[02-模块/Policy-Based/PPO]]  ← 近端策略优化，RLHF 的 RL 引擎
9. [[01-原子/Reward-Model训练方法]] ← 奖励模型的训练方式全景
10. [[05-应用领域/Post-Training/RLHF]] ← 完整 RLHF 流程（SFT → RM → PPO）
```

### 时间线

| 年份 | 事件 | 读哪个 |
|------|------|--------|
| 1992 | [[02-模块/Policy-Based/REINFORCE\|REINFORCE]]：最早的策略梯度 | 了解策略梯度的起源 |
| 2015 | [[02-模块/Policy-Based/TRPO\|TRPO]]：用 KL 约束稳定训练 | 理解 trust region 思想 |
| 2017 | [[02-模块/Policy-Based/PPO\|PPO]]：TRPO 的简化版 | **必读**，RLHF 的 RL 引擎 |
| 2022 | [[05-应用领域/Post-Training/RLHF\|RLHF]]：InstructGPT / ChatGPT | **必读**，完整 RLHF 流程 |
| 2023 | [[02-模块/Reward-Model/DPO\|DPO]]：跳过奖励模型 | 理解 DPO 的数学推导 |
| 2024 | [[02-模块/Policy-Based/GRPO\|GRPO]]：去掉 Critic | DeepSeek 的创新 |

### 阅读顺序总结

```
策略梯度 → KL散度 → Bradley-Terry → PPO → 奖励模型 → RLHF
    ↓                                              ↓
TRPO（历史）                              DPO（简化版）→ GRPO（最新版）
```

## 主题 6：彻底搞懂 PPO 及其变体

> 目标：从 TRPO 到 PPO 到 GRPO，理解策略优化的演进。

### 前置知识链

```
1. [[01-原子/策略梯度]]         ← ∇J = E[∇logπ · G]
2. [[01-原子/优势函数]]         ← A = Q - V
3. [[01-原子/GAE]]             ← 广义优势估计
4. [[01-原子/Trust-Region]]    ← KL 约束的思想
5. [[01-原子/KL散度]]          ← Forward vs Reverse KL
6. [[01-原子/Clip机制]]         ← 截断的重要性
7. [[01-原子/重要性采样]]       ← 用旧数据估计新策略
8. [[02-模块/Policy-Based/REINFORCE]] ← 最早的策略梯度
9. [[02-模块/Policy-Based/TRPO]] ← KL 硬约束
10. [[02-模块/Policy-Based/PPO]] ← Clip 替代 KL
11. [[02-模块/Policy-Based/GRPO]] ← 去掉 Critic
12. [[02-模块/Policy-Based/DAPO]] ← 解耦 Clip
```

### 时间线

```
1992: REINFORCE — 蒙特卡洛策略梯度，方差大
    ↓
2015: TRPO — KL 硬约束，保证单调改进，但计算复杂
    ↓
2017: PPO — Clip 替代 KL，简单有效 ← **最重要**
    ↓
2024: GRPO — 去掉 Critic，组内相对优势（DeepSeek）
    ↓
2024: DAPO — 解耦 Clip 的上下界（解决熵坍缩）
```

### 阅读顺序总结

```
策略梯度 → 优势函数 → GAE → Trust-Region → KL散度 → Clip机制 → 重要性采样
    ↓
REINFORCE → TRPO → PPO → GRPO → DAPO
```
