# 强化学习基础概念

## 专业术语

- **Agent（智能体）**：与环境交互的实体，根据当前环境状态 ( s_t ) 和策略选择动作 ( a_t )。
- **Environment（环境）**：具有动态状态的系统，会根据智能体的动作和自身随机性发生状态转移。
- **State（状态）**：( s )，表示环境在某一时刻的具体状态。
- **Action（动作）**：智能体根据环境状态做出的决策或行为。
- **Reward（即时奖励）**：( r )，智能体在执行动作后从环境中获得的即时反馈。
- **Policy（策略函数）**：( \pi(a|s) )，在状态 ( s ) 下选择动作 ( a ) 的概率，表现为概率密度函数（PDF），具有随机性。

## 反馈与价值

### 整体回报（Return）

整体回报 $U_t$ 定义为未来所有奖励的加权和：  
$$  
U_t = R_t + \gamma R_{t+1} + \gamma^2 R_{t+2} + \dots  
$$ $$
U_t = R_t + \gamma U_{t+1}
$$
其中：

- $R_t$ 表示在时刻 ( t ) 获得的即时奖励。
- $\gamma$ 是折扣因子，$0 \leq \gamma \leq 1$，用于平衡短期和长期奖励。
- $U_t$ 是一个随机变量，其随机性来源于未来状态和动作的不确定性。

### 动作-价值函数（Action-Value Function）

动作-价值函数 $Q_\pi(s_t, a_t)$ 表示在状态 $s_t$ 下执行动作 $a_t$，并遵循策略 $\pi$ 的期望回报：  
$$
Q_\pi(s_t, a_t) = \mathbb{E}[U_t | s_t, a_t]  
$$

- 期望消除了除 $s_t$、$a_t$ 和策略 $\pi$ 外的所有随机性。
- $Q_\pi(s_t, a_t)$ 仅依赖于当前状态、动作和策略。
>随机性来自于下一次动作和环境的随机性，虽然本次s和a给定了，但是下一次是不确定的

### 最优动作-价值函数（Optimal Action-Value Function）

最优动作-价值函数 $Q*_(s_t, a_t)$ 表示在所有可能策略 $\pi$ 下的最大期望回报：  
$$
Q*_(s_t, a_t) = \max_\pi Q_\pi(s_t, a_t)  
$$

### 状态-价值函数（State-Value Function）

状态-价值函数 $V_\pi(s_t)$ 表示在状态 $s_t$ 下，遵循策略 $\pi$ 的期望回报：  
$$
V_\pi(s_t) = \mathbb{E}_A[Q_\pi(s_t, A)]
$$

- 通过对动作 $a_t$ 求期望，消除了动作的随机性。
- $V_\pi(s_t)$ 用于评估当前状态 $s_t$ 和策略 $\pi$ 的优劣。

## 强化学习的学习方法

1. **Policy-Based（基于策略）**  
    直接学习策略函数 $\pi(a|s)$，优化智能体在给定状态下选择动作的概率分布。
    
2. **Value-Based（基于价值）**  
    学习动作-价值函数 $Q_\pi(s, a)$，通过估计每个动作的期望回报来指导决策。
    
3. **Actor-Critic（演员-评论家）**  
    结合基于策略和基于价值的方法：
    - **Actor**：学习策略函数 $\pi(a|s)$，决定动作选择。
    - **Critic**：学习价值函数（如 $V_\pi(s)$ 或 $Q_\pi(s, a)$），评估动作或状态的好坏。
