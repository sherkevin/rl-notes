# 按数据来源分类 (Data Source)

强化学习算法根据学习过程中是否与环境交互，可以分为Online和Offline两大类。

---

## Online RL (在线强化学习)

### 定义
学习过程中持续与环境交互，动态收集新数据并实时更新策略。

### 核心特征
- **实时交互**: 智能体与环境持续交互
- **动态数据**: 数据集不断更新和扩充
- **探索式学习**: 可以主动探索未知状态
- **闭环系统**: 学习→行动→观察→学习

### 工作流程
```
环境 → 状态 s → 策略 π(a|s) → 动作 a
  ↑                              ↓
  ┄┄┄┄┄┄┄┄ 奖励 r + 新状态 s' ┄┄┄┄┄┄┄┄
                ↓
            经验回放池 (动态更新)
                ↓
            更新策略 π
```

### 优点
- ✅ 可以主动探索，发现更好的策略
- ✅ 数据分布与策略分布匹配
- ✅ 适合未知环境的学习
- ✅ 理论相对成熟

### 缺点
- ❌ 需要大量真实交互（成本高）
- ❌ 在现实世界可能危险（如机器人、自动驾驶）
- ❌ 训练时间长

### 典型算法
- **On-Policy**: [[PPO]], [[TRPO]], [[A3C]]
- **Off-Policy**: [[DQN]], [[SAC]], [[TD3]]

### 应用场景
- ✅ 模拟环境训练（游戏、机器人仿真）
- ✅ 可低成本交互的场景
- ✅ 需要持续适应的环境

---

## Offline RL (离线强化学习)

### 定义
完全从固定的历史数据集中学习，学习过程中不与环境进行任何交互。

### 核心特征
- **静态数据**: 数据集是固定的、历史收集的
- **无交互**: 学习过程完全与环境分离
- **分布偏移**: 数据分布≠策略分布（核心挑战）
- **开环系统**: 只学习，不行动

### 工作流程
```
历史数据集 D = {(s₁,a₁,r₁,s₁'), (s₂,a₂,r₂,s₂'), ...}
    ↓
    ┄┄┄┄┄┄┄ 只从数据学习 ┄┄┄┄┄┄┄
    ↓
学习策略 π
    ↓
部署到环境（一次性评估）
```

### 核心挑战：分布偏移 (Distributional Shift)

**问题**：
- 数据集是由**行为策略** μ 收集的
- 学习的**目标策略** π 可能会做出数据集中没见过的动作
- 这导致价值估计错误，策略崩溃

**比喻**：
> 就像一个历史学家只看古代菜谱学习做菜，如果他创新了一个菜谱里没有的菜法，他无法知道这道菜好不好吃（因为没有数据）。

### 解决方法
1. **保守Q学习 ([[02-模块/Value-Based/CQL|CQL]])** - 降低对未见状态的Q值估计
2. **行为正则化** - 限制学习策略不偏离行为策略太远
3. **不确定性估计** - 对数据外区域降低信心

### 优点
- ✅ 不需要环境交互（安全、成本低）
- ✅ 可以利用海量历史数据
- ✅ 适合现实世界应用（医疗、金融）
- ✅ 数据可复用

### 缺点
- ❌ 无法主动探索
- ❌ 受数据质量限制
- ❌ 分布偏移问题
- ❌ 理论不成熟

### 典型算法
- **Batch RL**: [[CQL]], [[BCQ]]
- **行为克隆**: [[IQL]], [[AWAC]], [[02-模块/Actor-Critic/TD3|TD3+BC]]

### 应用场景
- ✅ 医疗治疗（不能在病人身上试错）
- ✅ 自动驾驶（真实道路测试成本高）
- ✅ 推荐（系统（用户日志丰富）
- ✅ 机器人控制（保护硬件）

---

## 对比总结

| 维度 | Online RL | Offline RL |
|:---|:---|:---|
| **与环境交互** | ✅ 持续交互 | ❌ 完全不交互 |
| **数据来源** | 实时收集 | 历史固定数据集 |
| **数据性质** | 动态增长 | 静态有限 |
| **探索能力** | ✅ 主动探索 | ❌ 无法探索 |
| **应用成本** | 高（需要交互） | 低（只用数据） |
| **安全性** | 可能危险 | 安全 |
| **核心挑战** | 探索效率、样本效率 | 分布偏移 |
| **学习范式** | 必然是 Off-Policy | 必然是 Off-Policy |
| **理论成熟度** | 成熟 | 发展中 |

## Online + Offline 混合策略

实际应用中，往往结合两者：

```
阶段1: Offline预训练
  从历史数据中学习初始策略
      ↓
阶段2: Online微调
  部署到环境，持续交互优化
```

**好处**：
- 利用Offline的安全和效率
- 利用Online的探索和优化

## 直观比喻

### Online RL：学开车
```
学员（智能体）持续在教练场（环境）练习
→ 每次开车后获得反馈
→ 根据反馈调整驾驶策略
→ 持续改进
```

### Offline RL：看视频学开车
```
学员（智能体）只看大量驾驶录像（数据集）
→ 分析录像中的驾驶行为
→ 学习驾驶策略
→ 不能试开，只能看完后直接上路考试
```

## 关系图

```
强化学习算法
    │
    ├─→ Online RL (在交互中学习)
    │     ├─→ On-Policy (PPO, TRPO)
    │     └─→ Off-Policy (DQN, SAC)
    │
    └─→ Offline RL (从固定数据学习)
          ├─→ Offline Off-Policy (CQL, IQL)
          └─→ Offline On-Policy (理论存在，少见)
```

**注意**：所有Offline RL必然是Off-Policy，但Off-Policy不一定是Offline
