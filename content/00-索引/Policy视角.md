# Policy 视角

> 从策略优化的角度，串联 RL 算法的演化脉络。关注"如何学习一个好的策略"。

---

## 核心问题

**如何学习一个策略 $\pi(a|s)$，使得期望回报最大化？**

这个核心问题衍生出多个子问题：
1. 如何估计策略的好坏？→ 价值函数、优势函数
2. 如何更新策略？→ 策略梯度、信任区域
3. 如何保证更新稳定？→ Clip机制、KL约束
4. 如何处理连续动作？→ 高斯策略、确定性策略
5. 如何处理多智能体？→ 集中训练分散执行

---

## 演化脉络

### 第一阶段：基础策略梯度 (1992-1999)

```
策略梯度定理 (1999)
    ↓
REINFORCE (1992)：最基础的策略梯度
    ↓
Baseline (1999)：减去状态价值，降低方差
    ↓
优势函数 (1999)：使用 Q-V 替代 G
```

**关键文档**：
- [[01-原子/策略梯度]]：策略梯度的核心思想
- [[02-模块/Policy-Based/REINFORCE]]：最基础的实现
- [[01-原子/优势函数]]：降低方差的关键技术

**核心问题**：高方差、样本效率低

---

### 第二阶段：Actor-Critic 架构 (1999-2015)

```
Actor-Critic (1999)：Actor学策略，Critic学价值
    ↓
A2C/A3C (2016)：并行化加速
    ↓
GAE (2016)：广义优势估计，平衡偏差-方差
```

**关键文档**：
- [[02-模块/Actor-Critic/A2C]]：同步版本
- [[02-模块/Actor-Critic/A3C]]：异步版本
- [[01-原子/GAE]]：优势估计的标准方法

**核心问题**：策略更新幅度难以控制

---

### 第三阶段：信任区域方法 (2015-2017)

```
TRPO (2015)：KL散度硬约束，保证单调改进
    ↓
PPO (2017)：Clip软约束，实现更简单
    ↓
GRPO (2024)：去Critic，组内标准化
    ↓
DAPO (2025)：改进Clip，动态采样
```

**关键文档**：
- [[02-模块/Policy-Based/TRPO]]：理论保证最强
- [[02-模块/Policy-Based/PPO]]：应用最广泛
- [[01-原子/Clip机制]]：PPO的核心创新
- [[02-模块/Policy-Based/GRPO]]：LLM对齐的标配
- [[02-模块/Policy-Based/DAPO]]：最新改进

**核心问题**：连续动作空间的高效学习

## 关键技术对比

| 技术 | 解决的问题 | 代表算法 |
|------|-----------|---------|
| **策略梯度** | 直接优化策略 | REINFORCE, PPO |
| **优势函数** | 降低方差 | A2C, PPO |
| **GAE** | 平衡偏差-方差 | PPO, TRPO |
| **Clip机制** | 限制更新幅度 | PPO, GRPO, DAPO |
| **KL约束** | 保证单调改进 | TRPO |
| **最大熵** | 鼓励探索 | SAC |
| **确定性策略** | 连续动作 | DDPG, TD3 |
| **组内标准化** | 去Critic | GRPO, DAPO |

## 学习路线建议

### 入门路线（理解核心思想）

```
策略梯度 → REINFORCE → 优势函数 → GAE → PPO
```

**预计时间**：2-3天

**关键收获**：
- 理解策略梯度的核心思想
- 掌握方差降低技术
- 学会PPO的实现和调参

---

### 进阶路线（掌握连续控制）

```
PPO → DDPG → TD3 → SAC → 最大熵原理
```

**预计时间**：3-4天

**关键收获**：
- 理解确定性策略梯度
- 掌握双Critic技术
- 学会最大熵框架

---

### 前沿路线（LLM对齐）

```
PPO → DPO → GRPO → DAPO → 各种RM方法
```

**预计时间**：5-7天

**关键收获**：
- 理解RLHF的完整流程
- 掌握隐式RM的思想
- 学会最新对齐算法
