# 按策略类型分类 (Policy Type)

> 使用Dataview自动展示分类下的所有算法

---

## 分类说明

强化学习算法根据**学习策略**和**行动策略**是否相同，分为On-Policy和Off-Policy。

### On-Policy (在策略)

学习策略和行动策略是同一个策略，算法只使用当前策略生成的数据进行学习。

**所有算法：**
```dataview
TABLE
  优化对象 as "类型",
  数据来源 as "数据",
  动作空间 as "动作"
FROM #on-policy
SORT file.name ASC
```

**核心特点：**
- ✅ 学习无偏
- ✅ 理论收敛性好
- ❌ 样本效率低
- ❌ 训练慢

**代表算法：** [[SARSA]], [[PPO]], [[TRPO]], [[A3C]], [[A2C]]

---

### Off-Policy (离策略)

学习策略和行动策略可以不同，算法可以使用其他策略收集的数据来学习。

**所有算法：**
```dataview
TABLE
  优化对象 as "类型",
  数据来源 as "数据",
  动作空间 as "动作"
FROM "02-模块"
WHERE contains(tags, "#off-policy")
SORT file.name ASC
```

**核心特点：**
- ✅ 样本效率高
- ✅ 训练快
- ✅ 可以从观察中学习
- ❌ 学习有偏
- ❌ 实现复杂

**代表算法：** [[Q-Learning]], [[DQN]], [[SAC]], [[DDPG]], [[TD3]]

---

## 核心区别

| 维度 | On-Policy | Off-Policy |
|:---|:---|:---|
| **数据来源** | 只用当前策略的数据 | 可以用历史/其他策略的数据 |
| **数据复用** | ❌ 不能复用 | ✅ 可以复用（经验回放） |
| **样本效率** | 低 | 高 |
| **训练速度** | 慢 | 快 |
| **学习偏差** | 无偏 | 有偏 |
| **策略数量** | 1个（学习=行动） | 2个（目标策略≠行动策略） |

---

## 经验回放 (Experience Replay)

Off-Policy的核心机制：

```
┌─────────────────────────────────────────┐
│         经验回放池 (Replay Buffer)        │
│  存储 (s, a, r, s') 四元组                │
└─────────────────────────────────────────┘
           ↑                    ↓
    行动策略持续写入      学习过程随机采样
```

**相关概念：** [[经验回放]]

---

## Offline vs Off-Policy

**重要区别：**

- **Off-Policy** = 一种**学习方法**
  - 数据是动态的（经验池持续更新）
  - 学习过程中仍在与环境交互
  - 例如：[[DQN]], [[SAC]]

- **Offline RL** = 一种**问题设定**
  - 数据是固定的（给定的数据集）
  - 学习过程中完全不能与环境交互
  - 例如：[[CQL]], [[IQL]]

```
Offline RL ⊂ Off-Policy RL
```
